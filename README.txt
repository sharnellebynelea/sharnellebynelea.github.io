SHARNELLE BY NÉLLÉA — CATALOGUE V1

Contenu :
- index.html : catalogue responsive avec filtres et panier de démonstration
- products.json : données des 19 références disponibles
- assets/S1.jpg à S19.jpg : photos produits originales

IMPORTANT :
Cette version est une maquette de catalogue et de panier. Elle n'effectue aucun paiement réel et ne stocke pas les commandes.
Le paiement Jèko, la base de données et l'espace administrateur sécurisé nécessitent un backend et des identifiants API marchands.
Les références S20 à S29 restent à intégrer après validation des photos et de leurs catégories.

Publication GitHub Pages :
1. Décompresser l'archive.
2. Envoyer index.html, products.json et le dossier assets à la racine du dépôt sharnellebynelea.github.io.
3. Activer Settings > Pages > Deploy from a branch > main > /(root).
